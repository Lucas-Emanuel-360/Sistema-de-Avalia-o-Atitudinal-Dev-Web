# Wireframes de baixa / média fidelidade

## Mobile — Professor

```text
┌───────────────────────────┐
│ Logo          [Perfil ▾]  │
├───────────────────────────┤
│ [Início] [Registro] [...] │
│                           │
│ Registro rápido           │
│ 1. Estudante              │
│ [Ana] [Gabriel] [Mariana] │
│ 2. Dimensão               │
│ [Colaboração] [Autonomia] │
│ [Participação] [...]      │
│ 3. Tipo                   │
│ [Potencialidade] [...]    │
│                           │
│ 3ª escolha salva registro │
└───────────────────────────┘
```

Histórico: lista cronológica; devolutiva: seleção do estudante, textarea e envio.

## Desktop — Coordenação / Núcleo

```text
┌──────────────────────────────────────────────────┐
│ Logo                                    [Perfil] │
├──────────────┬───────────────────────────────────┤
│ Painel       │  Visão pedagógica                │
│ Alertas      │  [Turmas] [Dimensões] [Alertas]  │
│ Turmas       │  ┌──────────────┬──────────────┐ │
│ Intervenções │  │ Gráfico      │ Alerta       │ │
│ Clima        │  │ por dimensão │ pedagógico   │ │
│              │  └──────────────┴──────────────┘ │
└──────────────┴───────────────────────────────────┘
```

Alertas: resumo visual e revisão contextual. Turmas: filtros de turma/aluno/dimensão. Intervenções: formulário e lista histórica. Clima: gráfico coletivo.

## Mobile — Estudante / Responsável

```text
┌────────────────────────────┐
│ Logo            [Perfil ▾] │
│ [Visão] [Evidências] [...] │
│                            │
│ Meu desenvolvimento       │
│ ┌────────────────────────┐ │
│ │ Evolução individual    │ │
│ │ ▰▰▰▰▰░░                │ │
│ └────────────────────────┘ │
│ [Autoavaliação / Diálogo]  │
└────────────────────────────┘
```

Estudante: autoavaliação e contestação. Responsável: acompanhamento, devolutivas e diálogo. Sem rankings individuais ou comparações entre colegas.
